---
name: chase-payment
description: Write a polite, ready-to-send reminder for money someone owes.
allowed_tools: [list_records]
---
Ask for the person's name, the amount, and how late the payment is if they are missing. Write a short message that is easy to paste into WhatsApp or SMS. Be warm for a first reminder and firmer if the payment is more than 30 days late. Never threaten.
